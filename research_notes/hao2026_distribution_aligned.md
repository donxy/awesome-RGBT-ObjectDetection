- **约定**：每项注明出处（节号 / 公式号 / 表号）。原文没有写的一律标注「原文未说明」，不做推测；个别由图表可推断但正文未明说的，单独标注为「图示/参数量推断」。

## 1. 结构

**检测器**：ViT-Base 编码器 + DETR 检测头（§4.1：「We use frozen ViT-Base [5] (86M params) with DETR [3] head」；参考文献 [3] 为 Carion et al. 2020 的原始 DETR，不是 Deformable DETR 或 DINO）。
**冻结范围**：整个检测器（ViT 编码器 + DETR 解码器，共 86M 参数）全部冻结，只训练融合模块（图 2 图注、§3.3 Stage 2）。
**预训练来源**：§3.1 式（1）将检测器表述为在 D_pretrain（如 COCO）上以检测损失训练得到；具体 checkpoint 与权重来源「原文未说明」。
**插入位置**：融合模块位于编码器输出与 DETR 解码器之间——输入是 RGB 与 IR 的 patch token 序列 F_rgb, F_ir ∈ R^{N×d}（d = 768，即 ViT-Base 维度；N 为 token 数，§3.2 举例 224×224 输入、16×16 patch 时 N = 197，含 1 个 [CLS]），输出 F_rect ∈ R^{N×d} 送回冻结检测头 H（图 2、§3.2、式（4））。
**两路编码器是否共享**：图 2 标注「Shared ViT Encoder」，且 86M 为单个 ViT-Base 的参数量级（图示/参数量推断）；正文未用文字明确两路是否同权重。
**融合模块三段结构**（§3.2）：

1. **跨模态注意力**（式（6））：8 头，d_k = 96/头，双向带残差——F_rgb^enh = F_rgb + Attn_rgb·V_ir，其中 Q_rgb = W_q F_rgb、K_ir = W_k F_ir、V_ir = W_v F_ir，W_q, W_k, W_v ∈ R^{d×d}；反方向同理得到 F_ir^enh。参数量 4.7M（§3.2 末）。式（6）只写了 Q/K/V 投影，未写输出投影；4.7M 的逐项构成「原文未说明」。
2. **自适应门控**（式（9））：F_concat = [F_rgb^enh; F_ir^enh] ∈ R^{N×2d}；G = σ(MLP(Mean(F_concat))) ∈ R^{2d}，Mean 为对 token 维求均值，MLP = Linear(2d→d) → ReLU → Linear(d→2d)；F_gated = F_concat ⊙ G。**G 是通道维向量、对所有 token 共享**。参数量 2.4M。
3. **融合 MLP**（式（10））：F_rect = MLP(F_gated)，MLP = Linear(2d→4d) → GELU → Linear(4d→d)。参数量 7.1M。

**参数总量的一处不一致**：正文多处称融合模块 13M（图 2、§3.1、§4.1），但分项 4.7 + 2.4 + 7.1 = 14.2M；总参数 99M（表 1）与「86 冻结 + 13 可训」一致。分项与总述对不上，原文未解释。
**显式逐模态权重**：没有逐模态标量权重。唯一的门控是上述通道维 G（对拼接后的 2d 通道统一门控）；token 级 softmax 注意力权重也不是模态权重。§4.4 有一句定性描述称门控「dynamically weights modality contributions based on reliability」，但结构上是通道门控，不是模态门控。

## 2. 分布建模

**拟合对象**：冻结 ViT 编码器输出的 **[CLS] token 特征** F_cls ∈ R^d（式（2）、§3.3 Algorithm 1 第 3 步），即**融合前**的单路编码器特征。而对齐损失作用于**融合后**特征的 [CLS]（F_rect^cls，式（4））——GMM 拟合未融合特征的分布、对齐融合特征，两者同为 768 维。
**用哪一路拟合**：Algorithm 1 只写输入为「target dataset's normal validation samples V (5k images)」，第 3 步为对每张 I_i 提 [CLS](E(I_i))；图 2 Stage 1 的「Normal Images」同时画了可见光与红外样例。究竟用 RGB、IR 还是两路都用，**原文未明确说明**（复现决定点，见第 8 节）。
**GMM 规格**：K 个分量（式（2））；**对角协方差** Σ_k（§3.1，参数量由 O(Kd²) 降为 O(Kd)）；**EM 拟合**，μ_k 以 **k-means++** 初始化，max 100 iter、tol = 1e-4；**K 由留出子集上的 BIC 选择，默认 K = 8**（Algorithm 1 第 4–6 步；§4.1 实验用 K = 8）。
**特征归一化**：是否对 [CLS] 特征做 L2 归一化或标准化，**原文未说明**。
**拟合时机**：Stage 1 离线一次性拟合，训练中保持固定（Algorithm 1 第 7 步；§3.3「remains fixed during fusion training」）。拟合耗时约 10 分钟（§5）。
**"目标域正常图像"的确切含义**（§3.3）：目标数据集的 validation 样本，经分层抽样筛选 **brightness ∈ [0.3, 0.7] 且 contrast > 0.4**，每个数据集 **5k 张**（§4.1）。§3.3 特别澄清：normal 指目标域中无严重退化的样本，「does not mean identical to the pretraining distribution」——建的是目标域良好曝光特征的参考区，不是预训练数据分布本身。各数据集 validation 划分的具体定义、亮度/对比度的度量方式，**原文未说明**。

## 3. 损失

**总损失**（式（4），§3.2 末）：

L = E_{(I_rgb, I_ir, Y)∼T} [ −log p_normal(F_rect^cls) + λ·L_det(H(F_rect), Y) ]，**λ = 0.5**。

注意形式：对齐项（NLL）权重为 1，检测项权重为 λ。p_normal 为式（2）的 GMM 密度；NLL 对 F_cls 的梯度形式见式（3）（后验概率加权的、朝各分量均值的拉力）。
**检测损失**：原文只写作 L_det(H(F_rect), Y)，其构成（匈牙利匹配、分类/回归权重等）**原文未说明**，只能按 DETR [3] 原文默认实现。
**其他正则**：除 AdamW 的 weight decay 1e-4（§4.1）外，无其他正则项的记载。
**梯度流向**：只更新融合模块参数 θ_M；检测器全程冻结，GMM 参数固定（§3.3 Stage 2 步骤）。按式（4）字面，−log p 项只直接作用于 F_rect 的 [CLS] 一行；patch token 只通过检测损失和模块内部耦合间接受梯度（此句为按公式的结构推论）。

## 4. 训练

**数据集**（§4.1）：LLVIP（15,488 对，行人）、FLIR（10,228 对，车辆）、DroneVehicle（28,439 对，航拍车辆）。
**优化设置**（§4.1）：AdamW，lr = 1e-4，wd = 1e-4，30 epochs，batch size 8，λ = 0.5；硬件 RTX 4090。学习率调度、warmup、数据增广、输入分辨率**原文均未说明**（§3.2 的 224×224 仅为 token 数的举例，不能当作实验输入尺寸）。
**训练数据的退化构成**：主实验训练集是否包含合成退化、包含哪些种类与比例，**原文未说明**。只有跨退化协议明确是「只用过曝样本训练」（§4.3）。
**退化生成参数**：过曝 / 欠曝 / 模糊如何生成、强度参数为何，**原文未说明**（全文无生成公式与参数）。§3.1 动机中提到雾，但实验退化只有过曝、欠曝、夜间、模糊。
**"训练快 4 倍"与谁比**：与同一 ViT-Base + DETR 上端到端训练的融合方法比——本文 3.5 小时，端到端基线 13–17 小时（表 1 Train Time 列）；§1 与 §6 表述为「from 14-17 hours to 3.5 hours」。表 1 未注明该时间对应哪个数据集，**原文未说明**。

## 5. 评测

**指标**：mAP@IoU = 0.5，3 次运行 mean ± std（§4.1）。
**评测划分**：总体 mAP（表 1）之外，按正常 / 过曝 / 欠曝 / 夜间分开报告（表 2，仅 LLVIP）。挑战子集的构造方式、样本量、与训练集的关系（是否同图不同退化），**原文未说明**。
**跨退化协议**（§4.3、表 3、表 4）：全部模型**只在过曝样本上训练**；已见 = 过曝，未见 = 欠曝、夜间、模糊。表 3 在同一冻结检测器 + 同一融合架构下比三种对齐目标：无对齐（仅检测损失）/ 对齐 P_degraded（GMM 拟合于过曝训练样本）/ 对齐 P_normal（本文）。表 4 再比 E2E（解冻）/ Frozen + Task Loss / Ours。图 4 给训练动态：对齐 P_degraded 的对齐损失约 15 epoch 平台化，对齐 P_normal 持续下降至 30 epoch。
**基线**（§4.1、表 1）：简单基线 Concat、Add；注意力类 CBAM、SENet、MMTM；端到端 SOTA：CFT、ICAFusion、CALNet、C2Former、M2FNet、CFMW；高级融合 CrossFormer、LRAFNet、RSDet。**全部基线由作者在同一 ViT-Base + DETR 上重新实现**，参数量与训练时间在此统一设置下测得。
**关键数字**：

- 表 1（mAP50，LLVIP / FLIR / DroneVehicle）：Ours **98.1±0.6 / 79.5±0.7 / 57.8±0.8**，总参 99M，3.5h；最强基线 RSDet 97.8 / 78.8 / 57.1，Concat 94.2 / 72.5 / 50.8。
- 表 2（LLVIP 场景拆分）：Ours 正常 97.8±0.5、过曝 47.3±1.3、欠曝 51.8±1.2、夜间 83.5±0.7；Concat 过曝仅 31.5±2.0。换算保持率（笔记计算）：过曝约 48.4%、欠曝约 53.0%、夜间约 85.4%。
- 表 3（对齐目标）：已见过曝——无对齐 43.5、P_degraded 48.2、P_normal 47.3；未见夜间——70.2 / 67.5 / **76.8**；未见模糊——30.8 / 28.5 / **40.6**。
- 表 4（跨退化）：Ours 已见过曝 47.3、未见欠曝 48.5 / 夜间 76.8 / 模糊 40.6；E2E 为 41.2 / 38.2 / 70.5 / 32.6；Frozen + Task Loss 为 43.5 / 41.8 / 73.2 / 35.8。

## 7. 与模态可靠性假设有关的内容

**何时压低哪一路**：无定量分析。全文没有给出门控 G 的统计分布、没有按退化类型拆分的门控行为、没有注意力图可视化。§4.2 只有定性叙述：过曝下 RGB 饱和、靠 IR 把特征拉回 P_normal；夜间增益较小因为「IR thermal signatures remain stable, requiring less alignment」。
**失败案例**：图 3 只展示基线失败、本文成功的定性对比，未展示本文方法的失败案例。§5 Limitations 定性承认：(i) 方法依赖预训练检测器质量与 GMM 的近似能力；(ii) 「When all modalities are severely degraded simultaneously, complementary information is limited」——但该条件在实验中并未实际评测（实验里 IR 始终可用）。§4.5 提到约 10% 的特征仍难以对齐（「approximately 10% remain challenging」），但检测性能仍大幅提升。
**模态缺失**：全文没有模态缺失（整路丢弃）实验，corrupted 与 missing 不作区分——准确说，missing 根本不在其协议内。
**「特征看起来正常但检测变差」类反例**：未报告。表 7 的叙事是对齐指标（W2、−log p）与 mAP 呈一致关系，即越对齐越准；没有给出对齐改善而检测变差、或对齐变差而检测改善的反例。唯一相关的张力在表 3：已见过曝上，对齐 P_normal（47.3）反低于对齐 P_degraded（48.2）——朝正常分布对齐在已见退化上并非最优，作者将其定性为以小的已见代价换未见泛化（§4.3）。

## 8. 歧义与缺失：复现时必须自行决定的事项
